# HeXe Brayton Transient Dataset v1

Multirate transient dataset for a compact Helium–Xenon (He–Xe) gas-cooled reactor coupled to a recuperated closed Brayton cycle. Generated by an independently implemented reference model for physics-informed neural-operator research.

## Contents
- `step6_dataset/production_v1/` – all trajectory arrays (2,177 cases)
- Dataset contract & manifest
- QA / integrity reports and file hashes
- Normalization and operator-design contracts

## Ten predicted states (order in `*_state.npy`)
1. Normalized reactor power  
2–7. Six delayed-neutron precursor concentrations  
8. Fuel temperature  
9. Structural-block temperature  
10. Bulk-coolant temperature  

## Fixed rated initial condition
All trajectories start from the same rated equilibrium:
- Reactor fission power ≈ 416 kW  
- Heat transferred to He–Xe ≈ 390 kW  
- Fuel temperature = 1056 K  
- Target electrical output ≈ 98 kW  
- Mass-flow rate = 3.31 kg s⁻¹ (fixed)  

Precursor concentrations are initialized at the six-group equilibrium corresponding to normalized power = 1 and zero net reactivity.

## Temporal representations
- **Global** (all cases): 601 points, 0–600 s at 1 s spacing  
- **STEP event-local** (STEP_HOLD cases only): 1,021 points over the first 5 s after onset (10 µs grid for the first 10 ms, then coarser transition)  
- **RAMP**: global grid only; exact onset and completion times retained as anchors  

## Partitions (trajectory-level, no leakage)
| Partition       | Cases | STEP event-local |
|-----------------|-------|------------------|
| TRAIN           | 1,025 | 512              |
| VALIDATION      | 256   | 128              |
| ID_TEST         | 256   | 128              |
| OOD_NEG_TEST    | 256   | 128              |
| OOD_POS_TEST    | 256   | 128              |
| STRESS_TEST     | 128   | 64               |

Normalization statistics were computed from TRAIN only and must be reused unchanged.
